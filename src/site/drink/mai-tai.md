title: Mai Tai
ingredientTags:
  - orgeat
  - orange curacao
  - lime juice
  - rum
ingredients:
  - 2 ounce rum (or multiple rums!)
  - ½ ounce orgeat syrup
  - ½ ounce orange curacao
  - ¾ ounce lime juice
  - Mint sprig (garnish)
  - Spent lime shell (garnish)
recipe: |
  Combine rum, orgeat, orange curacao, and lime in a shaker with ice and shake vigorously. Pour over ice. Garnish with mint and a spent lime shell tucked on the side.
notes: |
  This is Trader Vic's original recipe that I learned while attending an event at Pixar.

  I've learned the "spent lime shell garnish" originated in an era where lime squeezers didn't turn the lime inside-out. I now omit the lime shell if it's been turned inside-out because it looks ridiculous. The lime shell adds a bit of lime zesty goodness, so add it if you have right-side-in one handy!

  Optionally, you can float an extra ½ ounce dark rum over the top. This used to be my preferred garnish, but now I prefer without it. You do you, man.
